# Future Minds AI Academy

A responsive, static HTML5 website designed for GitHub Pages.

## Publish on GitHub Pages
1. Create a GitHub repository (for example `future-minds-ai-academy`).
2. Upload the contents of this folder to the repository root. Keep `index.html`, `styles.css`, `script.js`, and the `assets/` folder together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Customise
- Replace the `href="#"` values on the two training cards in `index.html` with your real programme URLs when ready.
- The logo is in `assets/logo.png`.
- Colours, layout, responsive breakpoints, and light theme are in `styles.css`.
- The scroll-driven blueprint stages and theme toggle are in `script.js`.
- The site uses Google Fonts when online and falls back to system fonts.

## Features
- Responsive layout for desktop, tablet, and mobile.
- Dark theme by default, with a user-controlled light/dark toggle saved in local storage.
- Scroll-activated story and evolving SVG blueprint (CPU → calculator → computer → network → AI agent).
- Reduced-motion preference support.
- No build step or framework required.
